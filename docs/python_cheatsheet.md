# V1.0 start
1.变量定义不需要指定类型，根据赋值自动推导类型。
2.打印输出使用print()函数，输出格式化字符串使用f"格式化字符串内容"。
3.注释使用#符号，单行注释或多行注释使用("""内容""")，docstring用于函数或类的文档说明。
4.条件判断使用if，elif，else语句，条件不使用括号，以冒号结束。
5.循环使用for，while语句，for循环格式为for 变量 in 循环对象:循环体，while循环格式为while 条件：循环体，注意while循环体累加只有a+=1,没有++的用法；通常条件必须以冒号结束。
6.函数定义使用def 函数名(参数列表)：函数体。参数列表中*args为参数时表示自动以元组形式输出，**kwargs为参数时表示自动以字典形式输出。装饰器使用@符号，有特定的装饰器@property.内置setter和getter主要用于设置和查询值时可增加判断。lambda是独有的匿名函数，返回值自动匹配。
7.模块导入使用import 模块名，例如import math。
8.if __name__ == "__main__":在python脚本中，主要用于保护脚本可执行部分，避免在导入时执行。
9.列表，字典：列表常使用的方法有增加：append()，删除：remove(),排序sort()，清空：clear()。字典常使用的方法有增加：update({键:值})，删除：del 字典[键]，清空：clear()，查询get（键，默认值），get查询不到可返回默认值。
10.类定义使用class 类名，类中可定义属性或方法，self表示类的实例对象，自己本身，方法的第一个参数必须是self，类初始化时使用__init__方法，初始化属性，相当于构造函数。
11.文件IO：with open("文件路径","模式") as 文件对象：文件操作。Json文件操作：import json模块，使用json.dump()方法写入json文件，ensure_ascii=False表示不使用utf-8编码可正常输出中文字符，使用json.load（）方法读取json文件。导入pathlib模块，使用Path类操作文件路径更方便。
12.异常处理：try-except语句，try语句中可能抛出异常的代码，except语句中处理异常的代码。
